# Profile repository: how it works

`README.md` renders on <https://github.com/Jubii100>. The prose is hand-written. The block between
`<!-- TRACK:START -->` and `<!-- TRACK:END -->` is generated by `scripts/track-record.sh` from repository
**metadata only**: counts, languages, dates. No code from any private repository is read or published.

## Privacy model
- `showcase.json` keys repositories by numeric GitHub id; it holds no repository names, only the titles chosen for display.
- A repository is printed only under the public title and line given in `showcase.json`. All others are
  counted and never named.
- `exclude` drops duplicates and repositories without the owner's own commits from every count.
- `external` adds organisation repos a fine-grained token cannot see (`{ "id", "language", "since", "until" }`); ignored when the token sees them.
- New organisation repos appear as "contributed to" automatically; add any without your own commits to `exclude`.

## Daily refresh (GitHub Actions)
`.github/workflows/track-record.yml` runs daily and on demand. Until the secret below exists it logs a
notice and leaves the README as committed.

1. Create a **fine-grained personal access token**: Settings → Developer settings → Fine-grained tokens.
   Resource owner `Jubii100`, *All repositories*, permission **Metadata: Read-only**, nothing else.
2. In this repository: Settings → Secrets and variables → Actions → New secret `REPO_LIST_TOKEN`.
3. Actions → *Track record* → *Run workflow*.

A fine-grained token sees only repositories owned by `Jubii100`. Organisation repositories you contribute to
are then missing from the count. Either add them under `external`, or use a classic token with `repo` scope
(broader: it can also write code, so it is riskier if it leaks).

## Local run
```
scripts/track-record.sh            # rewrite the block (uses your gh login)
scripts/track-record.sh --check    # exit 1 if the block is stale
```

## Adding a project
Get its id with `gh api repos/OWNER/NAME --jq .id`, add an entry under `showcase`, run the script, commit.
